# 🌤️ Global Weather App

A simple Flutter application to view **current weather information** for any city in the world.

## ✨ Features

- 🌍 Search weather data for **any city worldwide**
- 🌡️ See **temperature**, **pressure**, **humidity**, **wind speed**
- 🕰️ View **local time**, **sunrise**, and **sunset** for the selected city
- 🔍 **Search screen** with:
  - Search bar to find cities
  - **Search history** for quick access to previous queries

## 🧭 How to Use

1. Launch the app - you will see the weather in your city immediately
2. Tap the **Search button** at the bottom of the screen
3. Type in a city name and press enter
4. View detailed weather info including:
   - Local time
   - Temperature (°C/°F)
   - Humidity (%)
   - Atmospheric pressure (hPa)
   - Wind speed (m/s)
   - Sunrise and Sunset times
5. Your recent searches will appear in the history for easy reuse

## 🛠️ Tech Stack

- **Flutter** for cross-platform mobile development
- OpenWeatherMap API for real-time data
- Clean architecture with BLoC
